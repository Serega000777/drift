## 2. Физика машины (ядро, `Core/Vehicle`)
- Модель шины «нормализованное комбинированное скольжение» с эллипсом трения, нагрузочной чувствительностью, защитой от овершута на малой скорости. **[T]**
- Подвеска пружина/демпфер (сжатие/отбой)/отбойник/стабилизатор, высота крепления из статической нагрузки. **[T]**
- Рулевое с Аккерманом и скоростью рейки; статическое схождение. **[T]**
- Трансмиссия решателем последовательных импульсов: двигатель ↔ сцепление ↔ дифференциал(ы) ↔ колёса ↔ тормоза; **RWD / FWD / AWD** (межосевая муфта), open/LSD/сварка. Неявная линеаризация шины → стабильно на шаге 0.01. **[T]**
- Мотор: кривая момента, отсечка, торможение двигателем, холостой ход; авто-сцепление, авто-КПП по скорости земли (держит передачу в заносе), рев-матчинг, задний ход удержанием тормоза; ручная КПП. **[T]**
- Здоровье: температура шин от мощности проскальзывания, износ, прокол/разрыв (от износа, перегрева, удара), повреждения кузова по зонам и углам (схождение, пружины, мощность). После разрыва машину **тянет к лопнувшему колесу только за счёт сил** (тест на все 4 колеса). **[T]**
- Безголовый планарный стенд для тестов. Результаты: 0–100 ≈ 5.7 с (280 л.с.), 100–0 ≈ 41 м, стабильный пончик ~70°, восьмёрка с перекладками, 15 мин случайного ввода без NaN, независимость от FPS. **[T]**
- Паспорт авто (`VehicleSpecSheet`) → физпрофиль: синтез кривой момента по пику мощности/момента, передачи, главная пара, пружины по частоте, радиус из размера шин. Шаблоны: классические седаны 1.2/1.5/1.6 атмо (данные уровня ВАЗ-2101/2107/2106, приблизительно), JDM-купе турбо, евро-седан, ротор, V8, FWD-хот-хэтч, AWD-седан, родстер. **[T]**

## 18. VPS (`tools/setup/vps-setup.sh`, `vps-update.sh`, `docs/VPS_SETUP.md`)
- Схема «VPS сам забирает с GitHub»: ключ развёртывания только на чтение, доступы к VPS никому не передаются.
- `vps-setup.sh`: git, git-lfs, .NET 8, ufw (SSH/80/443), fail2ban, автообновления безопасности, опционально `--harden-ssh` (только ключи, без root; отказ, если у пользователя нет ключа), systemd-таймер каждые 5 мин.
- `vps-update.sh`: только fast-forward, `git lfs pull`, тесты ядра при новых коммитах, журнал `~/drift-status.log`; при локальных правках/расхождении — «update blocked», ничего не ломает.
- Проверено: `vps-update.sh` — на локальном bare-репозитории (нет изменений → выход; новый коммит → 120 тестов OK; локальная правка → блок; после очистки → OK); юниты systemd — `systemd-analyze verify`; `vps-setup.sh` — только `bash -n`. **На реальном VPS не запускалось.**
