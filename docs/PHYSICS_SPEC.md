# Физика Drift Career

Статус: геймплейная модель «Prototype B-lite». Проверена автотестами на планарном стенде; **в Unity и на реальной машине не калибровалась**.

## Соглашения
- СИ: кг, м, с, Н, Н·м, рад/с. Градусы — только в полях `*Deg`.
- Оси Unity: X — вправо, Y — вверх, Z — вперёд (левосторонняя). Положительный yaw поворачивает +Z к +X (по часовой сверху).
- Колёса: 0 FL, 1 FR, 2 RL, 3 RR. Угол руля > 0 — вправо. Схождение > 0 — toe-in.
- Угол заноса: между курсом и скоростью **в центре задней оси**; > 0 — машина повёрнута вправо относительно траектории. Так кинематический увод ЦМ в крутом повороте не считается дрифтом.
- Шаг физики 0.01 с (настраивается `Time.fixedDeltaTime`), трансмиссия — 2 подшага.

## Шина (`TireModel`)
- Продольное скольжение `sr = (ωr − v)/max(|v|, 2 м/с)`, поперечное `tanα = v_lat / max(|v|, 2)`.
- Нормализация на пиковые значения: `sx = sr/sr_peak`, `sy = tanα / tan(α_peak)`; комбинированное `s = |(sx, sy)|` → эллипс трения автоматически.
- Форма: `f(s) = s(2−s)` до пика (s=1, нулевая производная), далее `slide + (1−slide)·e^{−(s−1)·falloff}`.
- Нагрузочная чувствительность: μ падает с ростом нагрузки (`loadSensitivity`).
- Защита от овершута: сила ≤ `массаНаКолесо·|v_скольж|/dt` — убирает дрожание на малых скоростях при явном интегрировании PhysX.
- Покрытия (`SurfaceLibrary`) и компаунды (`TireCompound`) — множители: сухой асфальт 1.0, мокрый 0.72, снег 0.3–0.38, лёд 0.12 (шипы ×3.2).

## Подвеска
Луч из точки крепления вниз; `сжатие = ход + радиус − расстояние`. Сила = пружина + демпфер (сжатие/отбой раздельно) + отбойник, не отрицательная. Стабилизатор: ±k·(xL − xR). Высота крепления выбирается так, чтобы при статической нагрузке центр колеса был на высоте радиуса → машина спавнится в равновесии. Силы шины прикладываются на высоте центра крена оси.

## Трансмиссия (`VehicleSimulation`)
Последовательные импульсы на угловых скоростях (стабильно для жёстких связей):
1. Линеаризация шины по ω (численная производная) → эффективная инерция колеса `I + dt·r·K` (неявная схема).
2. Двигатель: `T = газ·кривая(rpm)·КПД − торможение двигателем − трение + поддержка ХХ`; отсечка.
3. Ограничения (8 итераций): сцепление (двигатель ↔ взвешенная сумма ведущих колёс, предел = ёмкость·включение), дифференциал оси (open: 0; LSD: преднатяг + коэф.·момент; сварка: ∞), межосевая муфта AWD, тормоза (предел по моменту, не меняют знак ω).
4. Финальные силы шин по решённым ω.
Привод: веса ведущих колёс RWD [0,0,½,½], FWD [½,½,0,0], AWD [s/2,s/2,(1−s)/2,(1−s)/2].

КПП: авто — по оборотам от скорости земли (держит передачу в заносе), кулдаун, рев-матчинг/отсечка при переключении; задний ход удержанием тормоза; ручная — E/Q. Авто-сцепление: по оборотам/скорости, выжимается ручником.

## Ассисты (только ввод)
Simulation — без изменений. Balanced/Assisted — скорость руля, уменьшение выворота на скорости (кроме заноса), контррулёжка к вектору скорости (сила уменьшается, если игрок рулит против), защита от разворота (срез газа при угле > порога), ABS-пульсация.

## Здоровье, повреждения, разрывы
- Температура: `dT/dt = P·1.7e-4 − (T − T_окр)·(0.08 + 0.004·v)`; сцепление по кривой температуры (оптимум 85–115 °C).
- Износ: `P·7e-8·множитель` за секунду; ≥1 → разрыв. Перегрев > 185 °C 5 с → разрыв.
- Удар: импульс > 1800 Н·с → урон зоны (перед/зад/лево/право) и ближайших углов; > 9000 — прокол (утечка 0.2/с), > 15000 — разрыв.
- Спущенное колесо: радиус −75 мм (сидит на ободе), сцепление ×0.5, сопротивление качению ×12, пик скольжения ×2.5. Увод возникает сам из сил (тест: машину тянет к лопнувшему колесу; задний разрыв на скорости ведёт к развороту).
- Урон угла: схождение до 3.5°, сцепление −15 %, пружина −35 %. Урон перед: мощность −45 %.
- Режимы: выкл / только визуал / полные.

## Оценка характеристик
`PerformanceEstimator` гоняет планарную модель: 0–100 с «хорошим водителем» (трекшн-контроль на старте), макс. скорость за 25–40 с, торможение 100–0, дрифт-рейтинг — контроллер руля и газа держит 38° с 15 м/с; рейтинг = доля времени в контролируемом заносе × стабильность угла. Это оценки нашей модели, а не реальные замеры.

## Ограничения и что калибровать
- Нет модели самовыравнивающего момента и гироскопии колеса; руль — без обратной связи.
- Планарный стенд использует квазистатический перенос веса; в Unity — полноценная подвеска (возможны отличия).
- Калибровать по ощущениям в Unity: `TireSpec` (пики, slide ratio), демпферы, скорость руля ассистов.
