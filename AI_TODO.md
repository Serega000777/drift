## Известные риски и непроверенное
- Ветки Unity 6/URP/Painter2D/Editor не компилировались без Unity → возможны мелкие ошибки API при первом открытии.
- Модель шины — геймплейная, не откалибрована по реальной машине. Цифры 0–100 и рейтинги — по нашей модели, это не реальные замеры.
- Спеки ВАЗ/JDM частично приблизительные (флаг `approximate`); реальные бренды не показываются в релизном UI без лицензии.
- Производительность на телефонах не измерялась.
