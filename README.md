# Drift Career

Мобильная (в первую очередь) дрифт-игра на **Unity 6 + URP** с одной общей физикой для мобилок, ПК (Steam) и консолей.
Сейчас играбелен **тестовый полигон «Академия»**: ангар → выезд на площадку 250×250 м → свободная езда, тренировки, режимы на очки, тандем с призраком, турнир, редактор препятствий, гараж с глубоким тюнингом, личный кабинет с персонажем и экипировкой. Первый запуск — экран загрузки и онбординг (возраст, согласия, гость или вход). Остальные трассы и онлайн — в меню с пометкой **«Скоро»**.

> Статус: код написан и проверен автотестами ядра (120 тестов) и компиляцией против референсных сборок Unity, **но ещё не открывался в Unity Editor**. Первый запуск — по `docs/UNITY_SETUP.md`. Что сделано и что дальше — `AI_DONE.md` и `AI_TODO.md`.

## Быстрый старт (ПК с Unity)
1. Unity Hub → установить **Unity 6 LTS** (+ Android Build Support).
2. Создать проект шаблоном **Universal 3D** где-нибудь отдельно, закрыть Unity.
3. Скопировать из него `Packages/` и `ProjectSettings/` в `UnityProject/` этого репозитория (или запустить `tools/setup/adopt-unity-template.ps1` / `.sh`).
4. Unity Hub → **Add project from disk** → `UnityProject/`.
5. Меню **Drift Career → 1. Setup Project**, **2. Setup URP Graphics**, **3. Validate Project**.
6. Открыть `Assets/_DriftCareer/Scenes/Bootstrap.unity` → **Play**. (Игра стартует даже из пустой сцены.)

Подробно, с ответами на типичные проблемы: [`docs/UNITY_SETUP.md`](docs/UNITY_SETUP.md).

## Управление
| Действие | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Газ / тормоз | W / S (↑ / ↓) | RT / LT | правые педали (глубина по высоте нажатия) |
| Руль | A / D (← / →) | левый стик | руль / слайдер / кнопки / наклон |
| Ручник | Пробел | A / RB | кнопка «Ручник» |
| Передачи (ручная КПП) | E или Shift / Q | Y / X | + / − |
| Пауза | Esc / P | Start | кнопка |
| Сброс / ремонт | R / F5 | Select | в паузе |
| Камера | C | правый стик (клик) | кнопка |
| Редактор полигона | Tab | D-pad ↑ | кнопка |
| Телеметрия | F1 / T | D-pad ↓ | — |

Задний ход в автомате: удерживать тормоз на месте.
